Elektron Capture is the engineering evidence acquisition subsystem for EDTS.
It records observations; it does not authorize builds or certify structural safety.

## How to use this package

1. Start with `CurrentStatus/PROJECT_STATE.md` (two minutes).
2. For the next coding task, read `Handoffs/IMPLEMENTATION_HANDOFF.md`.
3. For design “why,” read `Decisions/DECISION_LOG.md`.
4. For contracts, read `Specifications/`.
5. For process history, read `Memory/REPOSITORY_MEMORY.md`.
